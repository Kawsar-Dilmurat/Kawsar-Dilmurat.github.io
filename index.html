Project 01

TradeReconOps

Cross-border reconciliation and audit workflow platform

A finance operations platform for comparing USD bank transactions with CNY internal ledger records, separating normal FX variance from real accounting discrepancies, and generating audit-ready review outputs.

Python FastAPI PostgreSQL React Pandas CSV Processing AI Audit Summary
Watch Demo GitHub Repo README

What I Built

  • Designed a cross-border reconciliation workflow that compares USD bank records against CNY internal ledger data using transaction-level FX conversion.
  • Implemented deterministic classification logic for matched transactions, FX variance, amount mismatch, unmatched bank records, unmatched ledger records, and possible duplicates.
  • Developed review exposure and risk scoring calculations to help analysts prioritize high-impact reconciliation exceptions.
  • Built dashboard outputs for batch risk level, priority review queue, total review exposure, cash flow movement, and expected ending balance.
  • Generated Markdown audit reports and AI-assisted audit summaries while keeping financial classifications rule-based and explainable.

AWS-style cloud cost optimization dashboard

React TypeScript Node.js Express PostgreSQL Drizzle ORM OpenAPI

What I Built

Project 03

Stockwise

Inventory management with AI restock insights

A lightweight inventory management system for small businesses that tracks products, sales, restocks, and suppliers, then turns rule-based inventory metrics into readable restock recommendations.

Python FastAPI SQLAlchemy PostgreSQL React Docker AI Provider Layer
Watch Demo GitHub Repo README

What I Built

  • Developed database-backed product, sales, restock, and supplier workflows using FastAPI, SQLAlchemy, PostgreSQL, and React.
  • Implemented stock-out and stock-in logic so sales automatically decrease inventory and restocks automatically increase inventory.
  • Built rule-based inventory insight calculations including 7-day sales, average daily sales, estimated days left, reorder flag, suggested reorder quantity, and urgency tier.
  • Designed an AIProvider layer that turns structured inventory metrics into daily restock summaries and per-product recommendations.
  • Containerized the backend and database with Docker Compose for easier local setup and demo readiness.
