Frontend React

Engineering Highlights

  • Developed database-backed product, sales, restock, and supplier workflows using FastAPI, SQLAlchemy, PostgreSQL, and React.

Frontend React
Data / AI Pandas CSV Processing AI Audit Summary
Watch Demo GitHub Repo README

Engineering Highlights

  • Designed a cross-border reconciliation workflow that compares USD bank records against CNY internal ledger data using transaction-level FX conversion.
  • Implemented deterministic classification logic for matched transactions, FX variance, amount mismatch, unmatched bank records, unmatched ledger records, and possible duplicates.
